# Space-Shooter 🚀

## Overview
**Space-Shooter** is a 2D space shooter game built using **Python** and the **Pygame** module.  
The game focuses on smooth controls, collision detection, scoring mechanics, and an engaging arcade-style gameplay experience.

This project was created to strengthen my understanding of game development concepts and Python programming.

## Features
- Player-controlled spaceship movement
- Enemy spawning and movement
- Bullet firing and collision detection
- Score tracking system
- Game-over and restart logic
- Smooth animations using Pygame

## Technologies Used
- **Python**
- **Pygame**
- Object-Oriented Programming (OOP)
- Game loop and event handling
